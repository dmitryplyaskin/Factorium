# Локальный веб-интерфейс

## Запуск

```powershell
cargo run --release -- extract
cargo run --release -- serve
```

Если `data/game/catalog.json` уже существует, повторный экспорт не нужен.
Адрес по умолчанию: http://127.0.0.1:3410. Сервер слушает только локальный
интерфейс. Остановить его можно через Ctrl+C в терминале.

Другой каталог, порт или установка игры:

```powershell
cargo run --release -- serve --catalog data/my-game/catalog.json --port 3411 --factorio "D:\SteamLibrary\steamapps\common\Factorio\bin\x64\factorio.exe" --mods "D:\FactorioProfile\mods"
```

Параметры игры совпадают с CLI: `--data-dir`, `--mods`, `--builtin-only`,
`--timeout`; поддерживается `FACTORIO_BIN`. Без установленной игры можно
генерировать и экспортировать чертежи по готовому каталогу. Испытание в игре
тогда недоступно. Для испытания нужны та же версия игры и тот же набор модов,
с которыми создан каталог.

HTML, CSS и JavaScript встроены в Rust-бинарник. После изменения файлов `web/`
нужно пересобрать сервер и обновить страницу. Npm и внешние CDN не используются.
Иконки берутся из установленной игры; для неизвестных иконок есть замена.

Столбы размером 1×1 генератор сначала размещает между манипуляторами,
выбирая повторяющийся шаг по фактической зоне питания и длине провода.
На концах рядов шаг может быть короче. Для оставшихся потребителей, склада
и соединения сети используются дополнительные свободные места.
Если столб не помещается в промежуток, применяется общий поиск размещения.

В «Параметрах чертежа» включите **«Выход со стороны входа»**, чтобы сырьё
поступало слева, а готовый продукт выходил слева. Сундуки выходного склада
также размещаются слева. С общей входной шиной входы идут плотным пучком слева, а делители размещаются
у обслуживаемых рядов. Выходы рядов объединяются по фактическому потоку
с учётом вместимости выбранной ленты и 5% запаса выпуска. Поток, помещающийся
на одной ленте, имеет один внешний выход. При необходимости сборщик выравнивает
полосы, чтобы использовать полную вместимость ленты. Входы и выходы не выносятся
выше и ниже производственных рядов. Без обратного выхода входы шины
также остаются слева, а выходы размещаются справа. Со складом
ленты расходятся у сундуков, чтобы разместить манипуляторы и питание.
Для нестандартных прототипов с недостаточной дальностью подземных лент
генератор может использовать прежнюю разводку; направление входов всегда
указано на схеме и в таблице подключений.
Настройка сохраняется в браузере и проекте. Эквивалент CLI: `--reverse-output`.
Длинные линии с общей шиной и обратным выходом требуют больше времени на
доставку первых предметов. Если проверка сообщает о неустановившемся выпуске,
увеличьте прогрев в «Длительности испытания»; для большой схемы начните с 360 с
(CLI: `--warmup 360`).

## Работа с чертежом

Холст занимает всю ширину и высоту окна. Кнопки слева открывают панели поверх
чертежа: «Параметры», «Чертёж» (подключения и проверка), «Слои», «История».
Панель закрывается крестиком, повторным нажатием её кнопки или Esc.
Кнопка с глазом и клавиша H скрывают весь интерфейс; кнопка возврата остаётся.
На узком экране панель инструментов находится внизу.

В веб-просмотре конвейеры, делители и подземки показаны оригинальными игровыми
спрайтами в их исходных цветах. Используется статичный кадр без анимации.
Прямые участки и восемь поворотов выбираются по направлению и фактическим
соединениям лент; боковая загрузка на прямую ленту не меняет её форму.
У свободных концов показаны игровые окончания, у подземок различаются вход
и выход. Под делителями и подземками проходит такая же игровая текстура ленты.
Тонкие границы клеток помогают увидеть положение каждого блока.
Спрайты загружаются из установленной игры, без копирования в проект.
Поддерживаются обычные, быстрые, экспресс- и турбо-конвейеры. Когда спрайты
недоступны (в том числе у модов), используются условные обозначения
с приглушённым обрамлением и редкими стрелками направления.

У подземных конвейеров различаются вход и выход; пунктир показывает
соединение под землёй. Его можно скрыть в «Слоях» → «Подземные соединения».
При выборе конвейера информация о сущности показывает направление потока.
Входные ресурсы показаны значками на контрастной подложке поверх спрайтов
и проводов. Если в чертеже есть входные комбинаторы, значки привязаны к ним;
иначе они стоят рядом с подписями входов. Наведение показывает номер входной
линии, ресурс, подачу и полосу ленты, если два ресурса делят один белт.
Нажатие на значок открывает сведения о комбинаторе или входной ленте.
Эти обозначения скрываются вместе со слоем «Входы и выходы».

Здания, столбы, манипуляторы, сундуки и комбинатор также используют игровые
спрайты. Размеры, смещения, направления и тени взяты из выгрузки прототипов;
корпуса не поворачиваются как плоские иконки. Провода подходят к верхним
контактам столбов, зоны питания остаются привязаны к основанию. Статичная рука
манипулятора направлена к месту выгрузки; у длинной руки учитывается её вылет.
При выборе сущности рамка показывает занимаемые клетки.

Геометрия стандартных спрайтов хранится в `web/entity-graphics.json`, сами
изображения остаются в установленной игре и загружаются по мере необходимости.
Для неизвестных сущностей и несовпадающих ресурсов сохраняется условное
изображение. Обновить геометрию после новой выгрузки можно командой:

```powershell
python scripts/build_entity_graphics.py data/game/data-raw-dump.json "C:\Program Files (x86)\Steam\steamapps\common\Factorio\data"
```

В параметрах нажмите на текущий продукт, чтобы открыть каталог. Как в Factorio,
предметы разделены на группы (логистика, производство, компоненты, вооружение)
и ряды подгрупп. Группы берутся из игрового каталога, включая группы модов.
Поиск работает по русским названиям и игровым идентификаторам, не зависит от
регистра и различия е/ё, поддерживает несколько слов. При вводе поиск охватывает
все группы; затем можно ограничить результаты выбранной группой. Показаны только
рецепты, поддерживаемые генератором. Выбор предмета обновляет параметры;
для изменения открытого чертежа нажмите «Построить чертёж».

Горячие клавиши вне полей ввода: E — предметы, P — параметры, I — подробности,
H — скрыть или показать интерфейс. В каталоге Ctrl+F переводит фокус в поиск,
стрелки перемещают фокус между предметами, Enter выбирает, Esc закрывает окно.
На холсте стрелки перемещают схему, +/− меняют масштаб, 0 вписывает чертёж.


1. Выберите рецепт и требуемый выпуск в предметах в секунду. Интерфейс предлагает
   рецепты с одним, двумя или тремя твёрдыми ингредиентами и одним твёрдым продуктом, доступные
   текущему генератору. При смене рецепта выбирается совместимая машина.
2. Настройте оборудование и сгенерируйте чертёж. Модель вычисляет число машин,
   подачу с запасом, число линий, электрическую нагрузку и сеть столбов.
   Генератор автоматически сравнивает варианты отступов и длины рядов и выбирает
   компактную раскладку с проверенной геометрией и электроснабжением. Ради меньшей
   площади может понадобиться больше столбов или портов. Зеркальная пара рядов
   использует один выход с загрузкой двух полос; таблица показывает его один раз,
   с суммарной скоростью и отдельными требованиями к левой и правой полосам.
   Для двух и трёх ингредиентов появляется выбор длинного манипулятора.
   Для трёх компонентов генератор подбирает два или три входных белта по потоку.
   Два предмета могут занимать разные полосы одной ленты: в таблице у них
   одинаковый номер входа и координаты, но разные назначения полос.
   Левая и правая полосы указаны относительно направления движения ленты.
3. На схеме можно двигать и масштабировать вид, включать зоны питания и провода,
   выбирать сущности. Таблица соединений показывает предметы, скорости и
   координаты всех портов, включая подключение внешней электросети.
4. Во вкладке проверки запустите Factorio. Игра импортирует именно этот чертёж
   во временный профиль, прогревает производство и измеряет выпуск. Показываются
   фактическая скорость, временные окна измерения, связность сети и потребители
   без питания. Раздел «Выпуск по рядам и полосам» показывает фактический вклад
   каждого ряда; общий выпуск не скрывает остановку одного из них.
   Раздел «Подача ингредиентов» отдельно показывает заданную и измеренную
   подачу каждого предмета. Метрика подачи сырья суммирует входные потоки;
   таблица подключений показывает их по отдельности.
   Длительность прогрева и измерения можно настроить.
5. Скопируйте строку или скачайте файл через «Экспорт». В игре используйте
   импорт строки чертежа. SVG служит обзорной схемой; JSON проекта содержит
   параметры генерации, порты и расчёты; отчёт содержит результат испытания.

Изменение настроек помечает открытый результат устаревшим и блокирует его экспорт
и проверку до повторной генерации. Результат испытания привязан к конкретному
снимку чертежа. Статическая проверка и успешное испытание в игре отображаются
отдельно: расчётная скорость сама по себе не означает измеренную.

Сервер хранит последние 20 снимков в памяти, интерфейс показывает 6 последних.
После перезапуска сервера они исчезают, поэтому нужные результаты следует
скачать. Настройки формы сохраняются в браузере. Одновременно выполняется одно
испытание Factorio; оно продолжается при переключении на другой чертёж.

## Границы прототипа

Интерфейс использует существующий генератор одного производственного перехода.
Он не строит цепочку из нескольких рецептов. Жидкости, топливо, модули,
маяки, качество, вероятностные продукты и специальные механики пока исключены.
Нужные технологии должны быть изучены в игровом сохранении. Генератор не
размещает источник электричества: его нужно подключить к обозначенному столбу.
Для двух ингредиентов нужны машина не меньше 2×2 и электрический манипулятор
с вылетом два тайла. Для трёх ингредиентов нужна машина не меньше 3×2.
Рецепты с четырьмя и более ингредиентами пока не поддерживаются.

## Проверки разработчика

```powershell
cargo fmt --all -- --check
cargo clippy --all-targets --locked -- -D warnings
cargo test --locked
node --check web/app.js
node --test web/tests/model.test.js
```

API-тесты проверяют фильтрацию каталога, генерацию, экспорт, валидацию,
независимость снимков, ограничение истории и локальный доступ. Тесты JavaScript
проверяют соответствие формы снимку и интерпретацию результатов испытания.
Интерактивная проверка выполняется в браузере с реальной установленной игрой.
